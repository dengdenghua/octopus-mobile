远程指挥你的手机

把八爪鱼接到钉钉、Telegram、微信等聊天工具里——人在天边,发条消息就能让手机替你干活。

支持的远程渠道
1
六大渠道,任选接入
钉钉 飞书 QQ Discord Telegram 微信

接入后,在这些聊天工具里给八爪鱼发消息,就等于在对话页下达指令——手机在哪儿都听你的。

2
入口在设置里

接入入口统一在 App 的设置中:

八爪鱼→设置→找到远程渠道相关配置→选择要接入的渠道(钉钉 / 飞书 / QQ / Discord / Telegram / 微信)→按页面指引完成绑定

每个渠道的绑定流程略有不同,跟着 App 内的指引一步步走即可。

授权模型:陌生人指挥不动
3
按发送者逐人授权

八爪鱼的远程授权是按消息发送者逐人授权的:只有你明确授权过的人,发的消息才会被执行。

🙋 你自己已授权的发送者 可指挥
👩 你授权的家人已授权的发送者 可指挥
🕵️ 陌生人未经授权的发送者 指挥不动
🔒即使有人加到了同一个群、拿到了机器人账号,只要你没授权他,他发的指令一律不执行。
典型用法
🏢 人在公司,让家里的手机干活
你 · 在公司用钉钉发消息帮我看看家里手机还有多少电
八爪鱼 · 家里的手机当前电量 83%,正在充电。
你把今晚 8 点的闹钟改到 7 点半
八爪鱼已把闹钟从 20:00 调整为 19:30 ✅
＋
更多场景灵感

备用机当分身:旧手机常驻家里/办公室,通过 Telegram 远程差遣它查信息、发消息。

帮长辈远程代劳:在长辈手机上装好并授权你自己,长辈不会操作时,你发条消息就能远程帮忙搞定。

通勤路上先安排:人还在地铁上,先让家里手机把要用的东西查好、备好。

⚠️前提提醒:远程指挥要求手机上的八爪鱼保持存活——请确保无障碍已开启、常驻通知没被关,并按《无障碍开启与保活指南》做好各品牌保活设置。
