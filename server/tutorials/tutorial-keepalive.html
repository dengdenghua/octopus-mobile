无障碍开启与保活指南

无障碍服务是八爪鱼操控手机的核心能力。本篇教你开启它,并按手机品牌做好「保活」设置,让八爪鱼不被系统悄悄杀掉。

本篇内容
第一步:开启无障碍服务 第二步:分品牌保活设置 通用注意事项(必读)
第一步 · 开启无障碍服务
1
从 App 首页快捷进入

打开八爪鱼,首页的 任务控制台 卡片上有 去设置 按钮,点它可直接跳到系统无障碍设置页。

2
在系统设置中开启

如果想手动操作,路径是:

设置→无障碍→已下载的应用→八爪鱼→开启

系统会弹出授权确认,点同意即可。部分机型「无障碍」在「更多设置 / 辅助功能」里,搜索"无障碍"最快。

3
确认保活标志:常驻通知

开启成功后,通知栏会出现一条八爪鱼的常驻通知——这是前台保活生效的标志。

⚠️请不要在系统「通知管理」里把这条通知关掉,它一直在,八爪鱼才能稳定在后台待命。
第二步 · 分品牌保活设置
💡国产系统对后台管控很严,只开无障碍还不够。请找到你的手机品牌,把下面几项都设置好。
vivo / iQOOOriginOS

允许自启动

i管家→应用管理→权限→自启动→找到八爪鱼→允许

允许后台高耗电

设置→电池→后台耗电管理→找到八爪鱼→允许后台高耗电

最近任务加锁

打开最近任务(多任务界面),下拉八爪鱼的卡片,出现 锁定 图标即加锁成功,防止一键清理时被杀。

小米 / 红米MIUI / HyperOS

允许自启动

设置→应用设置→应用管理→八爪鱼→自启动 打开

省电策略改为无限制

同一页面→省电策略→选择 无限制

最近任务加锁

打开最近任务,下拉八爪鱼的卡片出现锁标即已锁定,清理后台时不会被杀。

OPPO / 一加ColorOS

允许完全后台行为

设置→电池→更多→应用耗电管理→找到八爪鱼→允许完全后台行为

允许自启动

在 自启动管理 中找到八爪鱼→允许自启动
华为 / 荣耀HarmonyOS / MagicOS

应用启动管理改为手动

设置→电池→应用启动管理→找到八爪鱼→关闭"自动管理"改为 手动管理

然后把三个开关全部打开:

允许自启动 允许关联启动 允许后台活动

通用注意事项(必读)
!
App 更新后要重开无障碍

八爪鱼覆盖安装更新后,Android 系统会自动关闭它的无障碍服务——这是系统机制,所有同类 App 都一样。

更新完请回到首页,通过 任务控制台 卡片的 去设置 重新开启一次即可。

!
常驻通知别关

那条常驻通知是保活生效的标志。用「通知管理」把它隐藏或关闭,可能导致八爪鱼在后台被系统回收,任务中途失败。

✅自查清单:无障碍已开启 ✚ 通知栏有常驻通知 ✚ 品牌保活三件套(自启动 / 耗电不限制 / 任务加锁)都设置好——八爪鱼就能长期稳定待命了。
