开始之前
1
邮箱注册,登录即用

打开八爪鱼,用邮箱 + 验证码登录:输入邮箱,收验证码,填入即完成。

✅平台自带模型积分,登录后直接就能用,不需要自己去申请、填写任何 API Key。
2
开启无障碍服务(核心)

无障碍服务是八爪鱼替你点击屏幕、操作 App 的核心能力,必须开启。

首页 任务控制台 卡片上点 去设置,或手动:

设置→无障碍→已下载的应用→八爪鱼→开启

开启后通知栏会出现一条常驻通知,这是服务正常运行的标志,别关它。

⚠️App 覆盖安装更新后,系统会自动关闭无障碍,记得回来重新开启一次。
3
做好保活设置(强烈建议)

国产手机的省电机制容易把后台 App 杀掉,导致任务中断。建议花两分钟按品牌设置:自启动、后台耗电不限制、最近任务加锁。

📖各品牌(小米 / vivo / OPPO / 华为等)的详细路径,见官方教程《无障碍开启与保活指南》。
说出第一句指令
4
在对话页下达任务

进入对话页,用底部的输入框打字,或按住说话直接语音下单。试试这些:

帮我打开 Wi-Fi 设置,连一下家里的网络
点一杯奶茶,少糖去冰,送到我常用的地址
查一下明天的天气,下雨的话提醒我带伞

八爪鱼支持多轮对话,能记住上文——你可以像和真人聊天一样追问、补充、改主意。

💡它还会记住你的偏好:说一句「我用饿了么不用美团」,以后点外卖它就默认用饿了么。
5
看它怎么执行

任务开始后,对话页的消息流里会持续给出执行进展和结果;需要操作其他 App 时,你能直接看到屏幕被自动点击、滑动——全程可见,随时能接手。

首页的 任务控制台 卡片也能看到任务相关状态。

更多玩法

浏览器:底部 浏览器 标签,首页有搜索框(Google 等引擎可切换)和常用网站。

小程序:在对话里直接说需求,八爪鱼能为你生成小程序;广场 里还能浏览、安装社区小程序。

远程渠道:在设置里接入钉钉 / Telegram / 微信等,人不在手机旁也能远程指挥,详见《远程指挥你的手机》。

进阶能力:可选配置 Shizuku(App 内一键免电脑),详见《Shizuku 全自动配置》。
